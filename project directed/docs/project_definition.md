# 프로젝트 정의서: FlowTask

## 1. 프로젝트 개요
**FlowTask**는 단순한 할 일 관리(To-Do List)를 넘어, **사용자의 현재 상황(페르소나)에 최적화된 성장 관리 방식**을 제안하는 맞춤형 생산성 플랫폼입니다. 사용자가 '학생', '취준생', '개발자' 등 자신의 역할을 선택하면, 그에 맞는 목표 설정과 관리 UI/UX를 제공하여 몰입도를 높이고 성취감을 극대화합니다.

## 2. 기획 의도 및 배경
기존의 생산성 도구들은 너무 일반적이거나(Generic), 특정 기능에만 치우쳐져 있어(Specific) 사용자의 맥락을 반영하지 못했습니다.
-   **학생**: 과목별 진도 체크와 복습이 중요합니다.
-   **취준생**: 기업별 전형 일정과 자기소개서 관리가 최우선입니다.
-   **개발자**: 사이드 프로젝트의 기능 구현, 버그 수정 등 명확한 마일스톤 관리가 필요합니다.

FlowTask는 이러한 니즈를 반영하여, 사용자가 **"나를 위한 도구"**라고 느낄 수 있는 경험을 제공하는 것을 목표로 합니다.

## 3. 핵심 가치 (Core Values)
1.  **Context-Aware (맥락 인식)**: 사용자의 역할에 따라 용어와 관리 방식을 다르게 보여줍니다.
2.  **Emotional Design (감성 디자인)**: 파스텔 톤의 부드러운 UI와 유리 질감(Glassmorphism)을 통해, 사용하는 것만으로도 기분이 좋아지는 심미적 만족감을 줍니다.
3.  **Visualized Progress (진척 시각화)**: 단순히 체크박스를 채우는 것을 넘어, 성장하고 있음을 시각적으로 보여줍니다 (분석 리포트).

## 4. 타겟 사용자
-   학업 성취도를 체계적으로 관리하고 싶은 **중/고등/대학생**
-   수많은 채용 공고와 전형 단계를 한눈에 보고 싶은 **취업 준비생**
-   사이드 프로젝트나 학습 로드맵을 관리하는 **주니어/예비 개발자**
