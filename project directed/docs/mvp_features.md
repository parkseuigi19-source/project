# MVP 기능 정의서 (Minimum Viable Product)

FlowTask의 초기 버전(MVP)에 포함된 핵심 기능 명세입니다.

## 1. 사용자 관리 (User Management)
-   **간편 로그인/가입**: 복잡한 절차 없이 `username` 입력만으로 사용자를 식별하고 접속합니다. (로컬 스토리지 기반 세션 유지)
-   **성장 타입 선택 (Persona Selection)**:
    -   최초 접속 시 학생, 취준생, 개발자 중 하나의 타입을 선택합니다.
    -   선택한 타입은 대시보드 상단 뱃지와 설정 등에서 확인/변경 가능합니다.

## 2. 목표 및 할 일 관리 (Goals & Todos)
-   **대시보드**: 핵심 기능을 수행하는 메인 화면입니다.
-   **목표 생성**: 큰 단위의 목표(예: "수학 정복", "A사 지원", "포트폴리오 제작")를 생성합니다.
-   **할 일(To-Do) 관리**: 각 목표 하위에 세부 실행 항목을 추가, 체크(완료), 삭제할 수 있습니다.
-   **진척도 표시**: 각 목표별 완료율이 시각적으로 표시됩니다 (분석 리포트 연동).

## 3. 회고 및 로그 (Retrospective & Logs)
-   **데일리 로그**: 하루의 배움, 감정, 특이사항을 줄글 형태로 자유롭게 기록합니다.
-   **에러/이슈 로그**: 문제 해결 과정을 기록하여 지식 자산으로 남깁니다.
-   **로그 조회**: 작성된 로그를 최신순으로 리스트 형태로 확인합니다.

## 4. 분석 리포트 (Analysis Report)
-   **종합 통계**:
    -   총 목표 수
    -   완료한 총 할 일 수
    -   전체 평균 달성률 (%)
-   **상세 현황**: 각 목표별 달성률을 프로그레스 바(Progress Bar) 형태로 시각화하여 제공합니다.

## 5. UI/UX 디자인
-   **테마**: 밝고 화사한 **라이트 파스텔 & 화이트** 톤.
-   **스타일**: **Glassmorphism** (유리 질감)을 적용하여 반투명하고 깊이감 있는 카드 UI 구현.
-   **인터랙션**: 마우스 호버 시 부드러운 움직임(Float)과 그림자 효과로 입체감 부여.
-   **반응형**: 데스크탑 및 태블릿 환경에 최적화된 레이아웃.
